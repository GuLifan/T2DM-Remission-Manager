## 二、关键使用约定（锁定）

1. **前台自然语言**：字段ID、规则ID、状态代码只存在于代码与文档中；医生界面显示中文字段名与自然语言结论（FR-0-01）。
2. **系统计算字段**：F040（最早可判定日期）、F047（客观缓解条件是否满足）由系统计算，不得由医生手工修改。
3. **医生确认字段**：F001–F005、F026–F029、F034–F036、F041–F048、F050、F053–F056 的最终值由医生确认；其中 F053/F054 不得仅凭药名由系统自动推断（正式药物字典后续另行锁定）。
4. **替代指标纪律**：FPG（F044）与 CGM 估算HbA1c（F045）仅在 HbA1c 不可靠（F043=否）时启用，且必须完成独立复核（F046=是）；本版本不建设 CGM 设备接口，eA1c 由医生手工录入（字段映射 F045 备注）。
5. **一次录入**：病程、BMI、分型、C肽、并发症不得在多个页面重复收集，后续只更新变化（FR-0-02）。
6. **字段字典范围**：本字段集是支撑全部临床分支的**最小必要字段集**，不区分"原型用"与"正式用"；凡无论如何填写都不改变分支、输出或医生决定的字段，一律删除或降为非必需（任务书§6 检查原则）。

## 三、输出模板清单（30 条锁定 `OUT-*` + 3 条 SYS 级提示）

| 组 | 模板ID | 场景 |
| --- | --- | --- |
| 事件1（5） | OUT-E1-ENTER / HOLD-ACUTE / HOLD-TYPE / HOLD-DATA / NOSTART | 进入完整评估/急性安全暂缓/分型存疑暂缓/资料不足暂缓/当前不启动 |
| 事件2（4） | OUT-E2-STABLE / INDUCTION / HOLD / NOSTART | 启动血糖稳定/启动缓解诱导/资料缺失暂缓/不启动 |
| 事件3（6） | OUT-E3-CONTINUE / ADJUST / SWITCH / END / ON-TREATMENT / OBS-ENTER | 继续/调整/转换阶段/结束/治疗下达标/进入观察 |
| 观察期（4） | OUT-A1-WAIT / DUE / RESTART-HIGH / RESTART-BENEFIT | 未到期/到期/因高血糖退出/因获益用药退出 |
| 事件4（6） | OUT-E4-NOT-DUE / ON-DRUG / OBJECTIVE-MET / CONFIRMED / NOT-MET / UNCERTAIN | 未到期/仍用药/客观满足/医生确认/未达到/暂不能解释 |
| 事件5（5） | OUT-E5-MAINTAIN / RISK / UNEVALUABLE / END / FOLLOWUP | 维持/风险上升/不可评价/终止/随访提醒 |

**SYS 级提示（3 条，非锁定临床模板）**：

| 模板ID | 用途 | 性质 |
| --- | --- | --- |
| `SYS-E1-CLOSE` | 分型复核明确为其他类型糖尿病时关闭本路径 | 未定义出口的兜底提示 |
| `SYS-E5-REVIEW` | 缓解后血糖暂不能解释时保留观察记录 | 未定义出口的兜底提示 |
| `SYS-ST00-REOPEN` | 从常规管理重新发起 60 秒预评估 | 操作提示（非临床结论） |

三者均**不表达临床结论**，不计入 30 条锁定文案。

**使用约定**：模板变量（{pre_tasks}、{stage_goal}、{interventions}、{next_review_date}、{earliest_assessment_date}、{last_med_stop_date}、{current_stage}/{old_stage}/{new_stage}、{adjustment_summary}）在渲染时替换为自然语言内容；模板正文为锁定文字，改动须走变更控制（README §六）。

## 五、工程与测试辅助字段（不属于临床字段 F001–F056）

> 下列字段用于测试隔离、审计或档案工程管理，不改变临床字段集，也不得自行作为临床分支条件。

| 所属对象 | 字段 | 约束 |
| --- | --- | --- |
| 账号 | `is_test_account` | 仅标记测试账号；必须与测试模式开关同时满足才开放测试能力 |
| 账号 | `simulated_date` | 测试账号的模拟日期；按账号持久保存，主动恢复真实日期时清空 |
| 患者 | `is_test_patient` | 测试患者标记；测试跳转与模拟日期下的临床写入只能作用于此类患者 |
| 事件 | `source='debug'` | 标识测试状态跳转产生的事件；不得计入正式临床统计 |
| 事件 | `simulated_date` | 记录事件实际采用的模拟日期；真实日期下为空 |
| 账号 | `department` | 医生注册时选填的所属科室，只用于展示与追溯 |
| 患者 | `department` / `contact_phone` | 当前科室必填并默认“内分泌科”；联系方式选填，有值时校验 |
| 患者 | `created_by` / `profile_complete` | 创建者与资料完善标记；批量导入置为未完善，完善前不得发起预评估 |
| 患者 | `height_cm` / `weight_kg` / `bmi` | 预评估首次采集的最新值与 BMI 快照；BMI 只显示数值，不作分级判断 |

**结构化表示**：F006 病程在界面和请求中使用“年 0–60 + 月 0–11”两个整数，并保留形如“2年3个月”的自然语言快照；F013 诊断基础采用单选 + 其他，F016 降糖药物采用多选 + 其他，仍分别落入原有 F013/F016，不新增临床字段编号。

**硬约束**：真实患者不得通过普通界面改为测试患者；测试模式关闭时所有测试接口返回 403；分发前停用测试账号并关闭测试模式。
