**M4 过程中发现并修正的问题**

| 问题 | 现象 | 处理 |

## 五、风险与依赖

| 风险 | 影响 | 应对 |
|------------------------|------------------------|------------------------|
| PyInstaller 对 Python 3.14 支持不足 | 打包路线受阻 | M1 实测；失败则项目内改用 3.13 虚拟环境（不动全局） |
| 《规则映射表 v0.4》《原交接稿》缺失 | 历史规则无法逐条溯源 | 以三份原文 + 锁定稿为准，记为已知缺口（`06` V1.0-Q-02） |
| 临床规则理解偏差 | 错误的临床分支 | 所有分支必须能追溯到锁定稿章节与规则 ID；3 病例 + 红线回归测试强约束 |
| 单机 SQLite 并发限制 | 多医生同时写入冲突 | 本版本明确单机/单 worker；并发需求出现时评估迁移 PostgreSQL |
| 本地登录被误当安全方案 | 合规风险 | 在 `07` 与界面说明中明确"可追溯性，非安全边界" |
| 依据材料为扫描件 | 检索不可用 | 已实测三份均为文本型；导入脚本对扫描件给出明确提示 |
| 范围膨胀 | 交付延期 | 任何新增需求先入 `06` 并评估，不在里程碑内夹带 |
