# 02 功能需求（FR）

> 早期2型糖尿病缓解管理软件（ETMMS）｜Spec 文档 02/08
> **版本**：v1.4｜**日期**：2026-09-24｜**状态**：有效（第二轮三批已实现并通过 Gate）
> 编号规则：`FR-<流程单元>-<序号>`，流程单元 1–6 对应任务书第六节（1 预评估 / 2 完整评估 / 3 阶段复评 / 4 缓解观察期 / 5 缓解判定 / 6 缓解后复评）；`FR-0-xx` 为跨单元支撑需求。
> 追踪键：规则ID（E1–E5、A1）、字段ID（F001–F056）、输出模板ID（OUT-*）、状态代码（ST00–ST99）与 `_DEV` 甲方材料（实现表系列）一一对应。

## 八、返回路径总表（FR-0-04 的核对基线，锁定稿§11）

| 场景 | 返回位置 |
| --- | --- |
| 预评估暂缓：分型存疑 | 明确为T2DM→直接进入事件2；明确为其他类型→ST99 关闭路径 |
| 预评估暂缓：急性不安全 | 完成急性处理后进入事件1结论处，或直接进入血糖稳定阶段 |
| 事件2关键资料缺失 | 补齐后返回事件2结论处，不重复入口 |
| 主动管理效果不足 | 留在事件3调整，不返回完整评估 |
| 明显血糖失控 | 返回血糖稳定阶段；出现急症先常规急症处理 |
| 观察期重新用药 | 因高血糖→事件3；因器官获益→记录暂不能判定状态 |
| 未达到缓解标准 | 直接返回事件3继续管理 |
| 缓解状态终止 | 直接返回事件3；仅新分型证据或重大临床变化才返回事件2 |
